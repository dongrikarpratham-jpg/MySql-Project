# MySql-Project

## About
This repository contains my MySQL project, including SQL queries, database design, table creation, and data manipulation.

## Technologies Used
- MySQL
- SQL

## Project Features
- Database and table creation
- Insert, update, and delete operations
- Data retrieval using SELECT queries
- Joins, filtering, grouping, and aggregate functions

## How to Run
1. Install MySQL Server and MySQL Workbench.
2. Open the `.sql` file in MySQL Workbench.
3. Execute the SQL queries to create and use the database.
